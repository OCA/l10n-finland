Configuration
=============

1. Install the module
2. Go to Settings > Contacts -> Partner Autocomplete > Manage Service
3. Switch the "Provider" to "PRH Avoin Data"
4. Uncheck "PRH industry" if you don't want to auto-create industries
5. Change "PRH Language" if you want the results in another language

Done! Just go to a contact and fill in a name or a business ID
